# vatech

Gestão de férias, ausências e licenças para pequenas empresas. Next.js 16 (`web/`), Laravel 13 API (raiz), MySQL 8.4, Filament v5, Electron (`desktop/`). Só PT na v1.

Ler antes de trabalhar:
- `.ai/guidelines/00-projeto.md` — stack, comandos, ambiente local, convenções
- `.ai/guidelines/10-fluxo-de-trabalho.md` — issue antes de código, testes em sessão separada
- `docs/PRD.md` · `docs/DECISIONS.md` · `docs/DESIGN.md` — produto, porquês, design
- `PROGRESSO.md` — estado actual

Regras: sem setas na UI; tokens de design só medidos ou documentados (senão `TODO: token em falta`); commits sem trailer de atribuição ao Claude.
